## 日本語

『幽幽子大人食欲不振』の、有志による**非公式**の修正ツールです。ゲームの作者（16air）とは関係ありません。
このツールはAI（Claude）を使って作成しました。

### 直せる症状

| 症状 | 使うもの |
|---|---|
| ゲームが起動しない | `vcredist_check.bat` |
| 1-3（3マップ目）に入ると止まって進めない（主に Intel / AMD の GPU） | `opengl32.dll` |

### 使い方

1. [Releases](../../releases/latest) から zip をダウンロードして展開する
2. Steam でゲームを右クリック →「管理」→「ローカルファイルを閲覧」でゲームフォルダを開く
3. 症状に合わせて、次のどちらか（または両方）を行う
   - **起動しない** → `vcredist_check.bat` をゲームフォルダにコピーしてダブルクリック。足りないものがあれば「Y」で、Microsoft 公式のインストーラーを使って入れます。
   - **1-3 で止まる** → `opengl32.dll` をゲームフォルダ（`player.exe` と同じ場所）にコピーするだけ

元に戻すときは、コピーしたファイルを削除するだけです。詳しくは zip の中の `README.txt` を見てください。

### 原因

- **起動しない**：32bit 版（x86）の Visual C++ 2010・2012・2013・2015-2022 が必要です。どれかが足りないと起動しません。
- **1-3 で止まる**：一部のタイルセット画像が縦 19200〜23040px あり、多くの GPU の上限（`GL_MAX_TEXTURE_SIZE` = 16384）を超えています。cocos2d-x がテクスチャを作れないため、マップが読み込めません。
  `opengl32.dll` は、上限を超える画像だけを GPU が扱える大きさに縮めて渡します。その分、該当する背景が少しぼやけることがあります。ゲームのファイルは書き換えず、ゲームのデータも含みません。

## English

An **unofficial** fan-made fix for *Yuyuko is suffering from lack of appetite*, not affiliated with the developer (16air). Made with the help of AI (Claude).

### What it fixes

| Problem | Use |
|---|---|
| The game does not start | `vcredist_check.bat` |
| Freezes when entering 1-3 (the 3rd map), mostly on Intel / AMD GPUs | `opengl32.dll` |

### How to use

1. Download the zip from [Releases](../../releases/latest) and extract it
2. In Steam, right-click the game → "Manage" → "Browse local files" to open the game folder
3. Depending on the problem:
   - **Does not start** → copy `vcredist_check.bat` into the game folder and double-click it. If something is missing, press "Y" to install it with Microsoft's official installers.
   - **Freezes at 1-3** → just copy `opengl32.dll` into the game folder (next to `player.exe`)

To undo, delete the copied files. See `README.txt` in the zip for details.

### Cause

- **Does not start**: the game needs the 32-bit (x86) Visual C++ 2010, 2012, 2013 and 2015-2022 runtimes. If any is missing, it will not start.
- **Freezes at 1-3**: some tileset images are 19200–23040px tall, more than many GPUs allow (`GL_MAX_TEXTURE_SIZE` = 16384). cocos2d-x cannot create the texture, so the map cannot load.
  `opengl32.dll` shrinks only the images over the limit to a size the GPU can handle, so some backgrounds may look slightly blurry. It does not modify game files and contains no game data.

## For developers

- `gl_proxy/` — source of the `opengl32.dll` proxy. `hook.c` hooks `glGetIntegerv(GL_MAX_TEXTURE_SIZE)` and `glTexImage2D`; every other export is forwarded to the system `opengl32.dll` (`stubs.c`, generated by `gen.py`). Build with `gl_proxy/build.bat` (Visual Studio 2022, x86).
- `vcredist_check.bat` — batch + PowerShell checker. Installers are downloaded from Microsoft and run only if their Authenticode signature is valid and from Microsoft Corporation.
- `make_release.ps1` — builds the release zip.
